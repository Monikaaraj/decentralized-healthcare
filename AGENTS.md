\## Rules



1\. Never use real patient data.

2\. Use synthetic or properly de-identified data only.

3\. Never put raw medical data on Polygon.

4\. Never put encryption keys on the blockchain.

5\. Never expose private keys or secrets.

6\. Never commit .env files.

7\. Never claim the AI is clinically validated.

8\. The AI is a research/demo risk prediction system.

9\. Never invent smart-contract functions.

10\. Never invent backend APIs.

11\. Read existing ABI/API specifications before integration.

12\. Do not modify another member's owned directories without agreement.

13\. Every major feature must have tests.

14\. Run tests before declaring a feature complete.

15\. Do not create a fake federated learning implementation.

16\. Raw hospital datasets must remain local to federated clients.

17\. Only model updates/parameters should be exchanged in the FL prototype.

18\. Do not store sensitive medical information in browser localStorage.

19\. Do not store private keys in frontend code.

20\. Keep architecture and API documentation updated.
